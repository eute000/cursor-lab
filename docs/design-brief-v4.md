# cursor-lab v4 设计提示词（自用工作稿）

## 风格定调（照用户图三）
- 一只黑猫：身体纯黑 #121217，外面套 1px 白边（暗色桌面才看得见）
- 眼睛是绝对主角：两颗巨大的白眼球（各占脸宽 1/3 以上，高 8px），黑瞳孔 + 1px 高光
- 耳朵是小三角，不追求尖长；不画胡须（32px 下只会变噪点）
- 粉色只留一点点（猫爪肉垫、图钉圆心），整体以黑为主

## 指针（用户图二 + 原话）
- 左上角一枚实心小三角当方向标识，尖端即热点，尺寸 9px，1px 白边
- 猫头放在右下，r=7，与三角留 2px 间隙，不粘连

## 符号类（用户图一：再细一点）
- 调整类：双箭头杆宽 3px（原来是 5），箭头头 9px，黑填充 + 1px 白边
- 禁止：黑圆 r=9 + 白斜杠 2px（白杠在黑底上才醒目），耳朵只留两个小三角
- 十字/I 型：1px 白边的细黑线，中心一颗粉点
- 猫爪：黑爪印 + 白边 + 粉肉垫
- 图钉：黑圆头 + 黑针尖 + 白边 + 粉心

## 硬约束
- 全部 32×32 整数像素，NEAREST 放大，绝不抗锯齿
- 每个造型四周至少留 2px 空白（用户反馈上一版"偏大"）
- 预览必须同时给 4 倍放大 + 1:1 真实尺寸（浅底/深底各一遍）
