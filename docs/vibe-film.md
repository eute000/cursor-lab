# 《一只猫》— 2 分钟概念短片

一部关于这个项目的**无旁白概念片**：讲一个人嫌 Windows 指针四十年没变，于是让 AI 做了一整套，最后只剩一句「你不需要会做，你只需要想要」。

- 成片：[`media/vibe-film.mp4`](media/vibe-film.mp4)（1920×1080 / 30fps / 2:07 / 13.8MB）
- 风格：vibe 知识大赏 —— 纯黑底、灰色层次、大字号排版、跟随音乐拍点（112.3 BPM）
- 音乐：BGM 为作者自备音轨（`VibeBGM`），发布时请在平台曲库内选择原声
- 字体：中文 Noto Sans SC / 英文 Bodoni Italic
- 生成方式：全部由代码逐帧渲染（`tools/film_v2.py`），无剪辑软件介入

## 结构

| 幕 | 时间 | 内容 |
|---|---|---|
| 起因 | 0:00–0:15 | 白箭头 → 四十年没变 → 系统指针 → 「我想改」→ 粒子重组成猫 |
| 想法 | 0:15–0:32 | 参考图 → 大眼睛·通体漆黑·猫爪 → 四版返工 → 「第四版对了」 |
| 做法 | 0:32–1:04 | 交给 AI → 代码 → 一图变一套 → 17 角色 → 三档尺寸 → 热点 → 点击三态 → 一条命令 → 装机 → 开源 → 投稿 |
| 产品 | 1:04–1:40 | 3D 玻璃环形相册 → 网格全亮 → 点击特写 → 桌面滑过 → 左右对比 |
| 结语 | 1:40–2:07 | 猫脸特写 → 「全程我只说了我想要什么」→「你不需要会做，你只需要想要」→ 引用 |

## 复现

```bash
python tools/beatmap.py        # 分析 BGM 拍点 → beatmap.npz
python tools/film_v2.py        # 逐帧渲染 → film_v2.mp4
```

依赖：Pillow + numpy + ffmpeg（渲染 3807 帧约 5 分钟）。
