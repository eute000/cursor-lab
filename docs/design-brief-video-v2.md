## 二、我们这版的定位（差异化）

参考片是 **5 分钟横屏长教程**；抖音流量更吃 **竖屏 60–90 秒**。所以做"同质感、不同长度"：

- **9:16 竖屏**，60–80 秒
- **上半屏真人**（占 45–55%，头顶留白 8%），**下半屏放画面**（屏录 / 光标特写 / GitHub 页面）
- 左上角**章节卡**（1/2/3/4 四步），每步 15–20 秒
- 底部**大字幕**：每屏 2–5 字一组，关键词换色（粉），不许整句铺满
- 转场：硬切 + 0.08s 轻微推近（punch-in），不要花哨转场
- 音效：只在"结果出现"时给一下（咔/咚），全程不加 whoosh
- 人声音量：-14 LUFS，音乐压到 -22dB（如果你给音乐）

## 四、你要录的东西（一步一步照做）

### A. 真人出镜（6 段，别一口气录太长）

1. **设备**：手机后置摄像头（4K/30fps）或电脑摄像头（1080p/30fps）。手机请**竖屏**拍。
2. **场景**：书桌，背后有书架/绿植/灯皆可，但**不能有晾衣架、床单、杂乱堆**。
3. **机位**：镜头和眼睛齐平（用书垫高），距离 60–80cm，人占画面**上半部分**，头顶留 8% 空。
4. **光**：主光在斜前方 45°（窗户或台灯），脸不要背光、不要顶光；晚上加一盏补光。
5. **视线**：看镜头（不是看屏幕）。提词器贴镜头旁边，别低头读。
6. **分 6 段录**，每段只说一句（就是上面表格里的粗体句子），**每条录 2 遍**，中间停 2 秒再停录。
7. **别做的事**：不要"嗯/那个/就是"，不要挥手挡脸，不要说"大家好"。

### B. 屏幕录制（20–30 秒，Windows）

用 **Win+G**（Xbox Game Bar）或 OBS 录，1080p/30fps，鼠标移动放慢：

1. 桌面空白处**按住左键 2 秒**（光标变握爪）→ 松开
2. 打开记事本，**打字 5 秒**（I 型光标加粗）
3. 浏览器里悬停一个链接，**按住 2 秒**（爪印握紧）
4. 打开 GitHub 仓库页，**慢慢往下滚 5 秒**
5. 打开 Pages 预览页，鼠标划过几个光标 5 秒
