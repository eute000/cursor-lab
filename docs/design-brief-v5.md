# cursor-lab v5 设计提示词（卡通版，自用工作稿）

## 角色（照用户给的小黑猫）
画一只**卡通风小黑猫**，姿态是趴着／探头的正面像：
- **头很大**，是一颗横着的圆润团块，占角色 2/3；头顶两个小三角耳，耳朵外侧与头齐平
- **两只超大白眼睛**是绝对主角：白色大椭圆几乎占满整张脸、左右几乎相触；每只眼里一颗大黑瞳孔，瞳孔左上角留一个白色小高光
- **身体很小**，缩在头下面，两侧露出两只小圆爪
- **尾巴细长**，从头后面伸出去、末端微微上卷
- 描边：**深棕黑**（比身体略暖），粗细约 1.2px；再外面套一道 **1px 米白**，这样放在任何桌面壁纸上都不会糊成一团
- 配色：身体近黑 `#1a181c`，白眼睛纯白，描边 `#30241e`，米白 `#fafafa`；红色只给禁止符

## 光标构成（照图 4 的排版逻辑）
- 指针（arrow）：左上角一枚**空心小三角 ▷** 交代方向，猫放在右下角，两者各自带米白描边、互不相连
- 带角色的：arrow / help / appstarting / wait / no / hand / person
- 纯符号的：crosshair（空心十字+中点）、ibeam（空心 I）、sizens/we/nwse/nesw/sizeall（空心双箭头）、uparrow（空心上箭头）、pin（图钉）、nwpen（笔）
- 动画：wait 与 appstarting 用**旋转圆弧**做 8 帧（不是像素点阵），转起来更像卡通

## 技术
- 每档尺寸（32/48/64）单独绘制，**8 倍超采样后 LANCZOS 缩小**——要平滑边缘，不许出现像素锯齿
- 所有造型四周留 ≥1.5px 空白；热点：指针在三角尖端，符号类在几何中心
- 预览：4 倍放大 + 1:1 真实尺寸，浅底/深底各一遍
