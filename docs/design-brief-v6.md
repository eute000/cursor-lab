# cursor-lab v6 设计提示词（微调版，自用工作稿）

## 统一版式（以 arrow 为母版，照图4）
所有"带猫"的光标**共用同一套版式**：猫固定在右下角、大小一致；左上角那个"角标"位放不同符号：

| 角标位 | 光标 |
|---|---|
| 空心小三角 ▷ | arrow |
| 空心问号 ？ | help |
| 小旋转弧 | wait |
| 红色禁行符 | no |

这样切来切去猫的位置不跳，只有角标在换 —— 整包看起来才像一套。

## 逐条修正
1. **ibeam 缩小**：现在 I 型高 23 格太抢眼，收到 **17 格**，两端横杠从 9 格收到 7 格，笔画 1.9
2. **help 去掉圆框**：只留一个手写感的问号当角标（字号 9），底下放猫，跟 arrow 完全同版式
3. **wait 用旋转弧当角标**：把 ▷ 换成 270° 旋转弧（两端带圆点），猫的位置/大小跟 arrow 一致；弧扫一圈 45°/帧，共 8 帧

## 不变的部分
- 猫：大头 + 超大白眼（黑瞳 + 左上高光）+ 小身体 + 圆爪 + 细尾巴，棕黑描边外套 1px 米白
- 技术：每档尺寸单独画、8 倍超采样 + LANCZOS；每个元素独立分层描边（高斯阈值膨胀）
- 版式四周留 ≥1.5px 空白；热点：三角在尖端、其余在中心
