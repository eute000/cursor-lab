## Description（10–1000 字符）

```
A cute black cat cursor set: a big-headed kitten with huge white eyes, dark brown line art
and a thin cream outline so it stays readable on both light and dark wallpapers.

Every cursor shares one layout: the cat stays at the bottom-right, while the top-left slot
carries the meaning — a hollow triangle for pointing, a question mark for help, an I-beam
for text, a rotating arc for busy, a red slash for forbidden. That way the cat never jumps
around when your pointer changes.

The set covers all 17 Windows cursor roles in 32/48/64 px layers (32 and 48 for the
animated ones): normal select, help, background working, busy (animated), precise select,
text select, handwriting, unavailable, the four resize arrows, move, alternate select,
link select, location select and person select.

The animated arrow idles with a very subtle tail sway and breathing, so the pointer feels
alive without being distracting.

MIT-licensed source and a build pipeline that turns any PNG set into a cursor pack:
https://github.com/eute000/cursor-lab
```
