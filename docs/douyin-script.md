# 抖音作品草稿：《我让 AI 给我做了一套鼠标指针，还送上了国外的收录站》

- 平台定位：抖音，9:16 竖屏，目标时长 **55–65 秒**
- 类型：vibe 知识大赏 / 过程展示
- 核心信息：**想法 → AI → 成品 → 真上线**，四步走完，普通人看得懂
- 一句话主打：不是"我写了个程序"，而是"我想要个东西，AI 帮我做出来了，别人现在能下载"

## 剪辑要点

1. **前 2 秒必须出现"变化"**（白箭头→黑猫），不要放头像、不要打招呼
2. 每个功能演示**不超过 3 秒**，用完就切，避免拖
3. 专业词只说一次，且必须用大白话补一句（"点击点"= 你点下去准不准全靠它）
4. 全程加字幕（很多人在静音刷）
5. BGM 用轻快电子/悬疑推进（前段低、展示段起），关键切换点加"咔"音效
6. 结尾不要放在"求点赞"，用"评论区点菜"制造互动理由
7. 发布时段建议：**19:00–22:00**（你这个内容吃上班族晚间刷）
