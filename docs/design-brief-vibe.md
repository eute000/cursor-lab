# 「vibe 知识大赏」风格提示词（自用规范，基于原片实看 + 开源逆向规范）

## 一、赛道是什么

不是教程、不是口播，是**用代码/AI 把硬知识做成"无旁白的影像诗"**：
音乐驱动 + 画面每秒都在动 + 大字排印 + 抽象装置/线描插画 + 底部字幕带。
参考片《虚无主义？然后呢》：2:46，**54.4 万赞 / 12.1 万收藏 / 11 万转发**，作者"叁号暗房 Logos"。
该赛道头部账号还有 @Iwanau / @Juno，用 Claude 直接生成 HTML Canvas 动画成片。

## 二、硬规格（逆向自 8 条原片 + 原片抽帧复核）

| 维度 | 规范 |
|---|---|
| 画幅 | **1920×1080 横屏**，30fps（这类片子都是横屏，竖屏会丢电影感）|
| 时长 | **2:00–2:45** |
| 声音 | **无旁白**，纯器乐 BGM **76–78 BPM**（沉静纪录片节奏），BGM 由代码合成，不买版权曲 |
| 底色 | 深蓝黑 `#0A0A1E`（不是纯黑，带一点蓝）|
| 布局 | 五区：水印（右下）/ 顶标签（左上小字）/ 中央动画主体 / 注释带 / 底部字幕带 |
| 运动 | 逐秒运动均值 **3.97**，静止秒 **<25%** —— 画面必须一直在动，没有"停着念字"的段落 |
| 严谨 | 结尾必有**引用来源 + 示意图免责声明**；历史图示必须标"示意图" |
| 字体 | 中文**大衬线**（思源宋体/宋体加大字距）做标题，中文无衬线做字幕；数字标数据用等宽 |

## 三、六段叙事弧（照抄就能用）

1. **冷开场钩子**（0–8s）：一句反常识大字 + 一个正在运动的抽象装置，无解释
2. **历史锚点**（8–45s）：把知识钉在具体年份/人物上，配"文献再现"风格插图（线描/版画），标注"示意图"
3. **机制动画模拟**（45–95s）：把抽象机制演出来（装置、粒子、计数、缩放推演），这里是信息密度最高的一段
4. **反直觉转折**（95–130s）：给一个"你以为…其实…"的翻转，画面配色/节奏突变
5. **现实落点**（130–155s）：回到"你"，给一个可带走的判断
6. **声明+引用**（155–165s）：小字列出事实来源，加"示意图"免责

## 四、给这个项目写的一版（《为什么鼠标指针永远是个白箭头》）

> 用赛道语言讲"指针设计 + 光标文件格式"，最后落到"所以我把它换成了一只猫"。不是教程，是概念片。

| 段 | 时间 | 画面（纯代码生成） | 文字 |
|---|---|---|---|
| 冷开场 | 0–8s | 黑底，一枚白色箭头从极小放大到铺满画面，边缘有细微颗粒噪点 | **「每一次点击，都经过它。」** |
| 历史锚点 | 8–42s | 线描装置：1981 Xerox Star → 1984 Mac 箭头 → 1995 Windows 沙漏，三代指针依次"点亮" | 「1981 年，它第一次被画出来」「一个箭头，用四十年」 |
| 机制 | 42–100s | **把 .cur 文件拆开**：三档尺寸（32/48/64）从同一张图分裂、堆叠；一个红色热点在网格上锁定；DPI 滑块从 100% 拉到 200%，指针在 32px 层变糊、48px 层变清晰 | 「它不是一张图，是一个容器」「尺寸错了，它就会糊」 |

| 收尾 | 156–166s | 小字引用：Xerox Star 1981 / Macintosh 1984 / .cur 文件格式；角标"示意图" | 「CursorLab · MIT」 |

## 五、技术路线（我这边的实现）

- **画面**：numpy 粒子 + PIL 逐帧绘制（辉光=多层高斯/缩放叠加，尘埃=随机种子固定），ffmpeg 30fps 编码；确定性种子保证可复现
- **音乐**：numpy 合成 76 BPM 极简 Bed（低频脉冲 + 高频噪音纹理 + 稀疏钢琴泛音），无版权风险
- **文字动画**：字距逐帧呼吸、遮罩擦除、逐字浮现、大字撞入（4 种，够用）
- **交付**：1920×1080 / 30fps / 2:45 以内 / ACC 音频 / 附 .srt
