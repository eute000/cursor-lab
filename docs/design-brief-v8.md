# cursor-lab v8 设计提示词（动态扩展，自用工作稿）

## 一、I 型也要"按下反应"
arrow 的按下态已成立（低头+眯眼+握爪），I 型照同一套：
- 猫：同一只、同位置，按下时 低头 0.45 格 + 眯眼 + 握爪（复用 press 姿势）
- I 本体：**按下去要像压进纸里**——笔画从 1.9 加到 2.4，整体下沉 0.4 格
- 由 click_fx 同时接管两个系统槽位：OCR_NORMAL(32512)=arrow_press、OCR_IBEAM(32513)=ibeam_press
- 这样在桌面按、在输入框里按，都有反应

## 二、手型（猫爪）做"抓取"动画
素材是四个趾垫 + 掌垫的爪印，动作要像"抓住又松开"：
- 8 帧循环，90ms/帧
- 整体缩放走 1.00 → 1.11 → 1.00 的余弦曲线（不是线性，线性会像机械抖动）
- 只缩放爪印本身，锚点在 (16,16)，保持居中
- 幅度上限 12%：再大就会盖住相邻文字

## 三、边界
- hand 从静态 .cur 变 .ani，文件会变大（可接受）
- 动画都在 32 格内完成，不越界；改完必须跑 audit 确认留白 ≥1.3 格
- 预览：hand 出 GIF，I 型出"按下前/按下后"对照
