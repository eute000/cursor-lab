# 声音与节奏规范 v3（顿挫 / 玻璃相册 / 音效）

> 依据用户 2026-11-01 第三轮反馈：
> 「炸开可以停顿一下，然后迅速合成，有一些顿挫感（在其他需要的地方可以大胆运用这些小巧思）」
> 「17 个光标排成圆环：由一个点开始快速旋转出场亮相，3D 旋转相册的效果，可以有些玻璃效果」
> 「有些地方可以适当加合适的音效」

## 一、顿挫感（hold-then-snap）

不是"一直匀速动画"，而是**蓄力 → 停顿 → 突变**。三段式：

| 阶段 | 时长 | 画面 |
|---|---|---|
| 蓄力 | 0.4s | 粒子向外炸开，速度递增 |
| **停顿** | **0.5s** | 粒子几乎静止（只做 ±2px 抖动），观众以为"卡住了" |
| **突变** | **0.1s（3 帧）** | 全部粒子瞬间收拢成实体，同时画面白闪一帧 + 音效"咚" |

这套语法可用在所有关键帧上：字形爆发、镜头切换、环形展开、结尾落款。

## 二、3D 玻璃相册（环形旋转）

| 参数 | 值 |
|---|---|
| 出场 | 中心一个**光点** → 炸开 → 17 张卡片从中心**向外甩出**并同时起转 |
| 环半径 | R = 560px，竖向压扁 0.38（略俯视） |
| 深度 | z = cos(θ)；缩放 0.55→1.0；亮度/透明度随 z 变化 |
| 遮挡 | 按 z 排序绘制，近的压远的 |
| 玻璃质感 | 半透明白 8% 填充 + 1px 边缘高光 + 斜向高光条（12%）+ 底部极淡倒影 |
| 转速 | 基础 8°/s，**每拍**加速一次（拍点脉冲），整体落在 112.3 BPM 网格上 |
| 中心 | 一团柔光，随拍呼吸 |

## 三、音效（全部 numpy 合成，无版权）

| 音效 | 合成方式 | 用在哪 |
|---|---|---|
| whoosh | 带通噪音 + 幅度包络（0.5s 起落） | 环形展开、镜头快推 |
| impact | 55Hz 正弦 + 噪音瞬态，60ms 衰减 | 合体/突变/标题砸入 |
| tick | 2kHz 短脉冲，12ms 衰减 | 逐个点亮角色 |
| riser | 高通噪音，幅度线性上升 1.2s | 转场前蓄势 |
| 混音 | SFX 压到 −18dB 左右，主音乐不动 | 全片 |

## 四、落点

- 第 5 镜（8.5–10.75s）改成 hold-then-snap
- 第 31 镜（64.0–72.5s）3D 玻璃环形相册 + whoosh/impact/tick
- 其余镜头遇到"关键帧"都可以套这套语法
