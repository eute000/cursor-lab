# cursor-lab v7 设计提示词（点击动态版，自用工作稿）

## 目标
让光标"活"起来：不点的时候轻轻动，按住的时候像被摸到一样有反应。
但要克制——桌面指针全天在动，幅度大一点就变成干扰。

## 一、常驻微动画（能用 .ani 直接实现）
只给主指针（arrow）做，12 帧循环，90ms/帧（约 1.1 秒一个周期）：
1. **尾巴轻摆**：尾尖上下 ±0.55 格做正弦摆动，中段跟一半，频率 1 次/循环
2. **呼吸**：整只猫 0.2 格的上下浮动（几乎看不见，但静止对比时能感到"活着"）
3. **耳朵轻抖**：只在第 4 帧和第 10 帧各抖 1 格，像被风吹到
原则：任何时候都不能让人"想关掉它"。幅度超 1 格就过了。

## 二、按下态（Windows 不支持，要小助手）
Windows 的光标没有 hover/active 状态，`.cur/.ani` 是死的。所以：
- 用 Python + ctypes 起一个常驻小进程，30ms 轮询鼠标左右键（GetAsyncKeyState）
- 按下瞬间：LoadImage 加载 `arrow_press.cur`，用 `SetSystemCursor(..., OCR_NORMAL)` 换上
- 松开瞬间：`SystemParametersInfo(SPI_SETCURSORS)` 从当前方案恢复
- 异常保护：try/finally + atexit 必须恢复，否则光标会卡在"握爪"状态
- 不做开机自启，用户要就手动双击 `click_fx_start.bat`

## 三、握爪帧长什么样
同一只猫、同一版式，只改三处：
1. **低头**：整个头下移 0.45 格（像被摸头）
2. **眯眼**：眼睛高度 4.8 → 3.2（舒服眯眼）
3. **握爪**：两只圆爪从扁椭圆收成小圆（像握住东西）

## 四、边界
- 鼠标移动太快时按帧切换可能闪一下，可接受
- 不改注册表、不需要管理员；退出程序即恢复
- 只影响当前登录会话
