安装

解压发行包，双击 安装.bat；或仓库里执行下面这条。

powershell -ExecutionPolicy Bypass -File install.ps1

还原：powershell -ExecutionPolicy Bypass -File uninstall.ps1

它是怎么来的

① 像素画

所有造型在 32×32 网格上按整数像素排，绝不做抗锯齿，最后统一加 1px 白边 —— 暗色桌面也看得见。

② 二进制编码

自己拼 .cur：BITMAPINFOHEADER + 自下而上的 BGRA + AND 掩码，热点塞进目录项的 planes/bitCount 字段。

③ 动画

.ani 是 RIFF/ACON：anih 头 + rate + seq + LIST('fram') 里 8 帧完整 .cur。

④ 安装

只写 HKCU\Control Panel\Cursors，安装前自动备份，随时一键还原成 Windows Aero。
